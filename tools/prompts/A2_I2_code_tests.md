## 항목별 지시

**L-021** — `linefee/market.py`, `market_data.py`의 5년 구간 시작일 계산이 2월 29일에도 동작하게. 날짜 계산만 떼어 단정으로 확인한다 (블룸버그 호출 금지).

**L-009** — `fetch()`가 저장하는 `as_of`가 영업일이 아닌 날이 되지 않게 한다 (공통 직전 영업일로 조정하거나 호가 기준일을 저장).
영업일이 아닌 `as_of`의 스냅샷을 `load()`가 만나면 원인을 알 수 있는 오류를 낸다. 날짜 로직은 블룸버그 없이 함수 단위로 확인한다.
`market_data.py`(구버전)의 같은 문제는 I1이 L-006/L-020에서 기본 저장을 막았다. 거기서는 날짜 계산만 같은 방식으로 맞춘다.

**L-015** — `load()`가 필수 키·테너를 검사한다. 빠지면 무엇이 빠졌는지 말하는 오류를 내고, 스냅샷의 `missing` 목록을
`MarketData`에 실어 화면(시장 데이터 캡션)에서 보이게 한다. 지금 스냅샷에서 값이 바뀌면 안 된다.

**L-018** — 스냅샷이 없을 때 `app.py`가 트레이스백 대신 안내(스냅샷은 로컬 전용, 받는 방법)를 보이고 멈춘다. 테스트 3개도 같은 안내로 끝난다.
루트에 `README.md`를 새로 쓴다: 무엇을 하는 도구인지, 설치, 실행, 스냅샷 2개(루트 = 회귀 기준, `linefee/` = 최신)의 차이와 준비 방법,
테스트 실행, 문서 위치. 실명·시장 원자료를 적지 않는다. 짧게.

**L-014** — 시장 객체 캐시 키에 스냅샷 파일 수정 시각을 넣고, `_ENGINE` 다시 읽기 목록에 `simm`을 넣는다 (의존 순서 주의: `simm`이 `linefee.regcap`보다 먼저).

**L-013** — 은행 파라미터 입력에 범위를 준다 (세율 0 이상 100% 미만, CET1 비율·변동성 배수·한계계수 0 이상 등). `validate()`도 params를 검사한다.
**금리 평균회귀(kappa)에는 `min_value`를 주지 않는다.** 음수 허용이 사용자 결정이고(L-010) 그 처리는 I3가 한다.
기본값은 바꾸지 않는다.

**L-012** — 상품을 통화스왑 → IRS·OIS → 통화스왑으로 바꿔도 두 다리 입력이 남아 있게 한다. `streamlit.testing.v1.AppTest`로
그 순서를 재현하는 확인을 `tests/`에 넣는다 (`tools/golden_check.py`의 `ui_layer`가 AppTest 사용 예).
위젯 key `preset`, 버튼 라벨 `계산`, `session_state["result"]`의 구조는 바꾸지 않는다 (golden 게이트가 쓴다).

**L-017** — `tests/test_curves.py`가 1주 테너와 CD 91일 예금도 재평가하게 한다. 허용오차와 문서 서술(`METHODOLOGY_v1.md`의 '0.005bp 이하')을
하나의 숫자로 맞춘다. 지금 최대 오차가 문서 수치를 넘으면 **커브 코드를 고치지 말고** 문서와 허용오차를 실측에 맞는 값으로 고치고,
impl 메모에 실측 최대 오차를 적는다. 새로 넣은 1주·CD 재평가가 실패하면 고치지 말고 `partial`로 기록하고 보고한다
(커브 값이 바뀌는 수정은 사용자 승인 대상이다).

**L-016** — `tests/verify_methodology.py`, `tests/regression_jpykrw.py`에 단정을 넣는다.
- 기대값은 파일 위쪽의 상수 표(`EXPECTED = {...}`) 한 곳에 모은다. I3가 방법론 변경 뒤 이 표와 문서 13장을 갱신한다.
- 날짜가 고정된 회귀 기준 스냅샷(`load_legacy`) 수치와 구조적 성질(동치, martingale, 표준오차 범위)만 단정한다.
  최신 스냅샷에 따라 달라지는 수치는 출력만 하고 라벨에 `m.as_of`를 쓴다.
- 기대값은 지금 코드가 내는 값으로 채운다. 문서 13장의 표와 다르면 고치지 말고 impl 메모에 차이를 적는다.
- 실패 시 종료 코드가 0이 아니어야 한다.
