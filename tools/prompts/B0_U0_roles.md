# B0 U0: 역할 분리와 거래상대방 마스터 (sonnet)

먼저 `tools/prompts/B_COMMON.md`를 읽는다. 역할은 ui다. `app.py`, `ui/**`, `.streamlit/secrets.toml.example`, `tests/test_app.py`, `README.md`만 고친다.

이 단계는 사용성 개선이 아니라 **기능 분리**다. 일반 사용자의 입력·결과 화면 구성은 가능한 한 지금대로 둔다 (기준 점수 r0를 여기서 재고, 개선은 다음 라운드의 U가 한다).
Streamlit을 유지한다.

## 만들 것 (DECISIONS O4, O5, O6, O10 / B_COMMON.md 화면 계약 1~9)

### 1. 역할 둘: 일반, 관리자

- 처음 화면은 일반 사용자(본부 세일즈)다. 로그인 없이 거래를 넣고 결과를 본다.
- 관리자 로그인: 사이드바(또는 눈에 덜 띄는 곳)에 비밀번호 입력(key `admin_pw`)과 `관리자 로그인` 버튼. 맞으면 `st.session_state["role"] = "admin"`, `로그아웃` 버튼으로 돌아온다.
  비밀번호는 `st.secrets["admin_password"]`와 비교한다(`hmac.compare_digest`). 비밀값 파일이나 키가 없으면 로그인을 막고 "관리자 비밀번호가 설정되지 않았습니다" 안내만 한다. 이때도 일반 화면은 그대로 동작해야 한다
  (`st.secrets` 접근이 예외를 낼 수 있다. 잡아서 처리한다).
- `.streamlit/secrets.toml.example`을 만든다: `admin_password = "여기에-바꿔-넣기"`와 쓰는 법 주석. 실제 `secrets.toml`은 만들지 않는다(gitignore, 사용자가 만든다).

### 2. 관리자 영역 (모든 위젯 key는 `adm_`로 시작)

지금 사이드바에 있는 것 가운데 다음을 관리자 전용으로 옮긴다. 일반 사용자 화면에는 그리지 않는다.

- 은행 파라미터: CET1 목표비율, 세후 요구수익률, 세율, USD·KRW 담보 조달 FTP 스프레드, KVA alpha, KVA 기준 커브, FBA 인정, BA-CVA 한계계수, 낸 IM 조달 스프레드.
- 시뮬레이션: 경로 수, 금리 변동성 배수, 금리 평균회귀(음수 경고는 유지, DECISIONS M14).
- 시장 데이터: 기준 선택, 블룸버그에서 새로 받기. 일반 사용자에게는 지금 쓰는 시장 기준(출처·기준일) 한 줄만 보여 준다.
- 거래상대방 마스터 조회·추가·수정·삭제.
- 관리자가 `저장`을 누르면 데이터 디렉터리의 `bank_params.json`, `counterparties.csv`에 쓴다(계약 6번). 저장한 값은 그 뒤 모든 사용자의 계산에 쓰인다.
  저장하지 않은 변경은 계산에 쓰이지 않는다. 범위 검사는 지금처럼 `BankParams.problems()`.
- 일반 사용자의 계산은 저장된 은행 파라미터(없으면 `BankParams()` 기본값)로 한다. 파일이 없을 때의 결과는 지금 화면의 기본값 결과와 같아야 한다.
- 관리자도 같은 화면에서 거래를 넣고 계산할 수 있다 (저장한 값으로).

### 3. 거래상대방 마스터

- 파일 형식과 읽는 순서는 계약 6번. 샘플 `data/counterparties.sample.csv`는 총괄이 써 두었다(가명 6행). 고치지 않는다.
- 마스터 항목(O6): 이름, 등급, 연 PD, CSA(없음 / VM / VM+IM), 딜러 라인 여부, 신용 위험가중치, BA-CVA 업종. LGD는 60% 고정.
- 일반 사용자: 고객은 마스터에서 이름으로 고른다(key `cl_name`. 딜러 라인이 아닌 행), 헤지 딜러도 이름으로 고른다(key `dl_name`. 딜러 라인인 행).
  등급·PD·위험가중치·업종·CSA 입력 위젯은 일반 화면에서 없앤다. 고른 상대방의 CSA 종류 정도를 글로 보여 주는 것은 된다 (계산을 이해하는 데 필요). 등급·PD·위험가중치 숫자는 보여 주지 않는다.
- 원화 IRS·달러 OIS의 헤지 상대는 CCP 고정이다. 지금의 CCP 이름·위험가중치 입력은 관리자 영역으로 옮기거나 상수로 둔다(값은 지금과 같게: 2%).
- 예시 거래는 마스터 이름을 가리키게 바꾼다(계약 7번). 로컬 마스터에 그 이름이 없으면 샘플 행을 쓴다.
- 실데이터 파일 `data/counterparties.csv`는 만들지 않는다(gitignore, 사용자가 관리자 화면이나 엑셀로 만든다). 실명을 어디에도 적지 않는다.

### 4. 테스트와 안내

- `tests/test_app.py`: 은행 파라미터 위젯을 보는 검사는 관리자로 로그인한 AppTest로 옮긴다(`at.secrets["admin_password"] = ...`, 환경 변수 `LINEFEE_DATA_DIR`는 임시 폴더).
  추가: 로그인 전 일반 화면에 `adm_` key가 없다 / 틀린 비밀번호는 거부 / 관리자가 CET1 목표비율을 바꿔 저장하면 일반 화면의 `result["params"].capital_ratio`가 바뀐다 /
  마스터에 행을 추가하면 `cl_name` 선택지에 나온다.
- `README.md`: 관리자 비밀번호 설정, 마스터 파일 위치, `LINEFEE_DATA_DIR`를 몇 줄로.
