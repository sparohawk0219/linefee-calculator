# 확정 결정 사항 (DECISIONS)

사용자가 확정한 방법론·운영 결정이다. 리뷰·구현·UI 개선에 참여하는 모든 에이전트는 작업 전에 이 파일을 읽는다.

**규칙**

- 아래 결정은 전제다. 타당성을 다시 묻거나, 결과 보고에 단서·대안 민감도를 붙이지 않는다.
- "코드·문서가 결정을 구현하지 않는다"는 정상 발견사항이다 (해당 category로 기록).
- "결정 자체가 틀렸다"는 의견은 `category: decision-conflict`로만 기록한다. 구현 대상이 아니며 사용자가 따로 본다.
- 이 파일은 사용자 승인으로만 바꾼다. 에이전트는 수정하지 않는다.

## C. 사람이 승인하는 지점

- Track A 발견사항 분류 (accept / reject / defer)
- 방법론에 닿는 모든 변경 (항목별 개별 승인), golden 기준값 재설정
- Track B 최종 수용
